# AVENOR 10X — Official Website

> **Tagline:** Every Sale. Accounted For.  
> **Brand & Engineering:** Independent Technology Company.

This repository contains the complete, modern, responsive, and production-ready corporate website for **AVENOR 10X**.

---

## 1. Technical Stack

- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Vanilla CSS Design Tokens
- **Typography:** Outfit (Google Fonts) exclusively across all components
- **Motion & 3D:** Framer Motion & CSS 3D Transforms (`rotateY`, `translateZ`, `perspective`)
- **Icons:** Lucide Icons (Monochrome SVG)

---

## 2. Strict Visual Identity

- **Monochrome Palette:**
  - Pure Black: `#000000`
  - Pure White: `#FFFFFF`
  - Controlled opacity variations for subtle architectural grids, borders, and overlays.
  - **Zero color gradients** or colored accents used.
- **Architectural Grid System:** Crisp background grid pattern with intersection crosshairs and vertical guide columns.
- **Custom 360° Framer Motion Carousel:** Smooth continuous rotation with hover pause, 3D card depth, and active service inspection.

---

## 3. Four Core Services

The company specializes in exactly four primary disciplines:

1. **Software Development** — Custom web, mobile, and database-driven software applications.
2. **Business Process Automation** — Automated sales and inventory pipelines, workflow connectors, and reporting.
3. **UI/UX Design** — High-precision user interfaces, intuitive interactions, and prototypes.
4. **IT Consulting** — System architecture guidance, software planning, and technology integration.

## 4. Key Sections & Features

1. **Header & Navigation:**
   - Wordmark and enlarged circular emblem container (`rounded-full`).
   - Compact `rounded-md` navigation menu featuring sleek icons with interactive hover tooltips.
   - Prominent "Let's Talk" CTA and accessible mobile drawer.
2. **Hero Section:**
   - Bold Outfit headline: "Building Smarter Systems for Business."
   - Interactive 360° rotating Framer Motion carousel with 3D cards for all 4 core services.
3. **About Section:**
   - "Technology With Purpose."
   - 3 Founding Principles: Practical Innovation, Thoughtful Engineering, and Business-Focused Technology.
4. **Services Section ("What We Do"):**
   - 4 service cards with comprehensive capability breakdown.
   - Interactive Service Modal for deep exploration and direct inquiry pre-population.
5. **Featured Product ("Clearer Sales. More Accurate Stock."):**
   - Sales & Inventory Management System preview.
   - 5-stage validation pipeline.
   - Interactive software comparison table simulating worker entries, discrepancy detection, and administrator approval.
6. **Process Section ("From Idea to Implementation"):**
   - 4-step engineering lifecycle: Discover, Plan & Design, Develop, Test & Improve.
   - Fluid wave path line weaving across the stage above rounded step cards.
7. **Projects Section ("Solutions in Practice"):**
   - Flagship Sales & Inventory Management case presentation.
   - Architecture diagram and forward-looking enterprise pipeline notice.
8. **Contact Section ("Let's Build Something Useful"):**
   - Functional inquiry form with field validation, budget selector, and core service dropdown.
   - Client session logging and unique reference ID generation (`AVX-XXXXXX`).
9. **Footer:**
   - Dynamic copyright year, service shortcuts, tagline, and back-to-top button.

## 5. Development & Build

### Install Dependencies
```bash
npm install
```

### Run Locally (Development)
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```

### Production Preview
```bash
npm run start
```
